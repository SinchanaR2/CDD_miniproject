# Road-Raksh: Road Damage Reporting and Monitoring System
Flask + SQLite + Leaflet/OpenStreetMap + Bootstrap, with Docker and GitHub Actions CI.

## Run locally
    python -m venv venv
    venv\Scripts\activate        (Windows)   |   source venv/bin/activate  (Mac/Linux)
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000



## Tests        pytest -q
## Docker       docker compose up --build
